Each theme is a drop-in Redmine 7 folder: themes/<name>/stylesheets/application.css and themes/<name>/javascripts/theme.js. Copy the folder into your install's themes/ directory and pick it under Administration › Settings › Display.

Every design ships in two navigation variants. Rail carries navigation in the left sidebar and hides Redmine's two nav bars, which would otherwise repeat the same links; sign-out moves to its own block at the foot of the rail. Classic keeps Redmine's own top and project menus and builds no rail. They are the same theme either way — only the navigation differs, and they are separate folders so you install whichever you want.

This preview loads the unmodified Redmine 7 core stylesheet from stylesheets/, exactly as a real install does, so what you see is what the theme does on top of stock Redmine. Redmine is GPL-2.0; so are these themes.
